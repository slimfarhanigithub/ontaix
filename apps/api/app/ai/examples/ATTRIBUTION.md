# Teach Example Sources And Attribution

`teach_examples.json` holds the worked examples of the teach extraction prompt. Each entry names its source in `source`, and every source is in the LEARN set of `split.json`.

## Ontaix Bake-Off Material

Entries with `source.set` `case` or `document` quote the teach bake-off cases and documents. That material is original writing produced for Ontaix; its organisations are fictional, except the owner's own example names (Insight, ADNOC and its business units) and the name AT&T used in a role-pattern case. It holds no private or customer text.

## GoodRelations

Entries with `source.id` `goodrelations` quote single sentences of the GoodRelations Language Reference (http://purl.org/goodrelations/v1.html).

- Work: GoodRelations Vocabulary for E-Commerce and its Language Reference, by Martin Hepp.
- Licence: Creative Commons Attribution 3.0, https://creativecommons.org/licenses/by/3.0/ (the licence the Language Reference states for itself).
- Attribution: This work is based on the GoodRelations ontology, developed by Martin Hepp.
- Changes: short extracts only; each sentence is paired with an extraction answer written for Ontaix.

## W3C Organization Ontology

No entry quotes the W3C Organization Ontology or its Recommendation (https://www.w3.org/TR/vocab-org/, W3C Software and Document License). It is TEST material and never an example source.
